# App Description
Health Insurance, Inc. utilizes an Azure-hosted Software-as-a-Service (SaaS) architecture utilizing GitHub for all source code and Node.js based Application Programming Interfaces (APIs).
#### Key Components:
- Blood Pressure
- Body-Mass Index (BMI)
- Risk Calculation
- Risk Categories
